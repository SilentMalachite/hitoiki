# Hitoiki

[English](README.md) | 日本語

Hitoiki（一息）は、過集中を止めるための macOS / Windows 用の常駐アプリです。設定した間隔または時刻に
全画面を数回フラッシュさせ、そのあと休憩が終わるまで暗いオーバーレイとカウントダウンで画面を覆います。

## 機能

- **2 種類のスケジュールを併用できる**: N 分ごと（既定 50 分）と、`15:00` のような決まった時刻。
  同じ分に重なった休憩は 1 回にまとめます。
- **全モニター同時にフラッシュ**。1 秒に 3 回を超えて点滅しません（周期 334ms 以上）。
- **休憩オーバーレイ**: 全モニターを半透明の黒で覆い、大きなカウントダウンを表示します。キー入力を
  受け取り、ほかのアプリへ切り替えられてもフォーカスを取り返します。
- **緊急解除**: Esc を 3 秒長押し（進捗をリングで表示）。短押しでは解除されません。
- **ディスプレイの変化に追従**: フラッシュ中・休憩中にモニターをつなぐ・外す・配置を変えると、
  覆う・外す・合わせ直すを自動で行います。
- **トレイだけで動く**: メインウィンドウは無く、macOS では Dock にも出ません。次回の休憩時刻は
  トレイのツールチップに出ます。
- **軽くて外に出ない**: 設定は JSON ファイル 1 つ。ネットワーク通信もポーリングもしません。待機中は
  オーバーレイ用のウィンドウを持たないので、レンダラープロセスも動きません。

## インストール

Apple の Developer ID や Windows のコード署名証明書では署名していません。そのため、ダウンロードした
アプリを初めて起動するときは OS の確認を通す必要があります。

### 自分でビルドする

Node.js 22 が必要です。

```bash
git clone https://github.com/SilentMalachite/hitoiki.git
cd hitoiki
npm ci
npm run dist
```

`npm run dist` は、配布物を作りたい OS の上で実行してください。出力先は `release/` で、macOS では
`.dmg` と `.zip`、Windows ではインストーラの `.exe`（NSIS）ができます。

自分の Mac でビルドしたアプリはダウンロード扱いにならないので、下の承認手順なしで起動できます。

### macOS での初回起動

macOS 版は ad-hoc 署名だけをしています。ダウンロードしたアプリを初めて開くときは次のとおりです。

1. `hitoiki.app` を開きます。アプリを検証できないという表示が出たら **完了** を押します。
2. **システム設定 → プライバシーとセキュリティ** を開きます。**セキュリティ** の欄に hitoiki が
   ブロックされたという表示があるので、その横の **このまま開く** を押します。
3. パスワードを入力し、**このまま開く** で確定します。

2 回目以降は普通に開けます。macOS 14 以前なら、Finder でアプリを右クリックして **開く** を選ぶ方法でも
構いません。

### Windows での初回起動

SmartScreen で「Windows によって PC が保護されました」と出た場合は、**詳細情報** → **実行** を押します。

## 使い方

Hitoiki はメニューバー（macOS）または通知領域（Windows）に常駐します。メニューは次のとおりです。

| メニュー | 内容 |
|---|---|
| 今すぐ休憩 | すぐに休憩を始める |
| 休憩時間 ▸ 1 / 3 / 5 / 10 / 15 / 30 / 60 分 | 休憩の長さ。設定ファイルの `breakSeconds` に保存する |
| 30 分間停止 / 再開 | 30 分間止める／すぐに再開する |
| 設定ファイルを開く | 設定ファイルを開く |
| 設定を再読込 | 設定ファイルを読み直す |
| 終了 | アプリを終了する |

休憩中に **Esc** を 3 秒長押しすると、休憩を途中で終えられます。

Hitoiki は同時に 1 つしか起動しません。ログイン時の自動起動は備えていません。自動で起動したい場合は
ログイン項目に追加してください（macOS: **システム設定 → 一般 → ログイン項目**、Windows:
`shell:startup` フォルダにショートカットを置く）。

## 設定

**設定ファイルを開く** で開いて編集し、**設定を再読込** で反映します。ファイルは初回起動時に既定値で
作られます。

- macOS: `~/Library/Application Support/hitoiki/config.json`
- Windows: `%APPDATA%\hitoiki\config.json`

```json
{
  "intervalMinutes": 50,
  "clockTimes": ["15:00", "17:30", { "time": "12:00", "breakSeconds": 3600 }],
  "flashCount": 3,
  "flashIntervalMs": 400,
  "flashOpacity": 0.85,
  "flashColor": "#FFFFFF",
  "fadeMode": false,
  "breakSeconds": 180
}
```

| キー | 既定値 | 範囲 | 内容 |
|---|---|---|---|
| `intervalMinutes` | `50` | `0` または 1〜480 | N 分ごとに休憩する。起動・再開・スリープ復帰の時刻から数える。`0` で無効。 |
| `clockTimes` | `[]` | | この時刻（ローカル時刻）に休憩する。要素は `"HH:mm"`、またはその時刻だけ休憩の長さを変える `{ "time": "HH:mm", "breakSeconds": n }`。 |
| `flashCount` | `3` | 1〜10 | 休憩前に点滅する回数。 |
| `flashIntervalMs` | `400` | 334〜2000 | 点滅の周期（ミリ秒）。周期の前半に光る。 |
| `flashOpacity` | `0.85` | 0.1〜1.0 | 点滅の最大不透明度。 |
| `flashColor` | `"#FFFFFF"` | | 点滅の色（CSS の色指定）。 |
| `fadeMode` | `false` | | `true` でふわっと明滅し、`false` で瞬時に切り替える。 |
| `breakSeconds` | `180` | 10〜3600 | 休憩の長さの既定値（秒）。 |

- 範囲外の数値は最も近い境界値に丸めます。型が違う値は既定値に戻し、`"HH:mm"` でない時刻は無視します。
- JSON として読めないファイルのときは、既定値で動き、ファイルには手を付けません。問題は標準エラーに
  出します。
- 間隔の休憩と時刻の休憩が同じ分に重なったときは 1 回にまとめ、時刻側の長さを使います。時刻どうしが
  重なったときは長いほうを使います。
- 休憩中に次の休憩の時刻が来ても、その回は飛ばします。

## 制約

- Hitoiki は「促す」道具で、「締め出す」道具ではありません。OS レベルの入力フックを使わないため、
  Cmd+Tab / Alt+Tab で切り替えた直後の一瞬のキー入力は、フォーカスを取り返す前にほかのアプリへ届く
  ことがあります。Esc の 3 秒長押しでいつでも休憩を終えられます。
- 設定画面はありません。JSON ファイルを直接編集します。トレイから変えられるのは休憩の長さだけです。
- 対象外: 統計、ポモドーロの細かな管理、複数プロファイル、自動更新。
- Electron を含むため、配布物は 150MB 前後になります。

## 開発

```bash
npm ci
npm run build   # tsc → dist/
npm test        # vitest
npm start       # dist/main.js を Electron で起動
npm run dist    # electron-builder でパッケージ化 → release/
```

```
src/main.ts            アプリのライフサイクル、トレイ、配線
src/scheduler.ts       次回の休憩時刻と、1 本だけのタイマー（Electron を import しない）
src/config.ts          設定の読み込み・検証・保存（Electron を import しない）
src/overlay.ts         オーバーレイのウィンドウ群: idle → flashing → breaking → idle
src/preload.ts         レンダラーに公開する最小 API（onFlash, onTick, cancel）
src/ipc.ts             IPC のチャンネル名
renderer/overlay.html  フラッシュと休憩の画面（CSS と JS を内包）
test/                  vitest のテスト（Electron はモック）
```

仕様は [SPEC.md](SPEC.md) にあり、動作についてはこれが正です。[CLAUDE.md](CLAUDE.md) と
[AGENTS.md](AGENTS.md) はコーディングエージェント向けの作業指示です。
